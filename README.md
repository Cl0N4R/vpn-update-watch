# پایش آپدیت برنامه‌ها

ابزار شخصی برای بررسی روزانه نسخه‌های جدید ۸ برنامه اندرویدی.

- زمان بررسی: هر روز ساعت ۱۳:۰۰ به وقت تهران
- منبع: GitHub Releases رسمی هر برنامه
- گزارش آخرین بررسی: `reports/latest.md`
- فهرست برنامه‌ها: `config/apps.json`

برای افزودن یا حذف برنامه، فقط فهرست `apps` در فایل `config/apps.json` را تغییر دهید.
