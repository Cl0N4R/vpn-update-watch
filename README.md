# VPN Update Watch

پایشگر روزانه Releaseهای رسمی فقط برای ۸ پروژه Android شبکه/VPN تعریف‌شده در `config/apps.json`.

## زمان‌بندی
GitHub Actions هر روز ساعت 08:45 تهران (05:15 UTC) اجرا می‌شود. اجرای دستی از زبانه **Actions** و گزینه **Daily VPN release watch** ممکن است.

## خروجی‌ها
- `reports/latest.md`: گزارش خوانا شامل نسخه، تاریخ، Stable/Pre-release، یادداشت توسعه‌دهنده، لینک Release و APKهای ARM64 که نامشان معماری را مشخص می‌کند.
- `reports/latest.json`: همان داده‌ها به شکل ساختاریافته.
- `state/seen_releases.json`: نسخه‌هایی که قبلاً دیده شده‌اند.
- `state/pending_ack.json`: Releaseهای جدیدی که هنوز کاربر اعلام نکرده از آن‌ها مطلع شده است.

## تأیید آگاهی
پس از آنکه کاربر در ChatGPT گفت «متوجه شدم»، مورد مربوط باید از `state/pending_ack.json` حذف شود و فایل commit شود. تا پیش از آن موارد pending در گزارش‌های روزانه تکرار می‌شوند. این مرحله فعلاً دستی است؛ گفت‌وگوی ChatGPT به‌تنهایی فایل GitHub را تغییر نمی‌دهد.

## محدودیت‌ها
- فقط GitHub Releases بررسی می‌شود؛ پروژه‌ای که Release ندارد ممکن است از طریق tag/commit به‌روزرسانی شده باشد.
- تشخیص ARM64 بر اساس نام asset است، نه بررسی محتوای APK؛ حداقل Android و معماری باید از توضیحات سازنده بررسی شود.
- ابزار توصیه نصب/عدم نصب نمی‌کند.
- مخزن عمومی است؛ هیچ کانفیگ VPN، توکن، ایمیل خصوصی یا داده حساس در آن قرار ندهید.
- فهرست پروژه‌ها را فقط در `config/apps.json` تغییر دهید.
